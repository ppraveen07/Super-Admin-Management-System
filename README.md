# Super Admin Dashboard

A responsive Super Admin Management Dashboard built using **React, TypeScript, Vite, HTML, and CSS**.

The application provides an admin interface for managing **Dashboard, Users, and Tenants** with a modern purple-themed design.

---

## 🚀 Features

### Dashboard

- Total Tenants
- Total Users
- Active Tenants
- Inactive Tenants
- Recent Tenants
- Quick Actions
- Platform overview
- Responsive statistics cards

### Users

- View users
- Search users
- Filter users by status
- Display user email
- Display tenant information
- Display user status
- Add User button

### Tenants

- View tenants
- Search tenants
- Filter tenants by status
- Display tenant administrator
- Display number of users
- Display tenant status
- Add Tenant button

### UI

- Responsive layout
- Purple admin theme
- Sidebar navigation
- Active navigation state
- Header
- Statistics cards
- Data tables
- Status badges
- Search boxes
- Dropdown filters
- Responsive mobile layout
- Separate CSS files
